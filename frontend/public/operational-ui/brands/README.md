# Bundled service identity icons

These PNG files are copied byte-for-byte from the reviewed Mezan finance design assets (`mezan-finance-design/dist/brands`, 21 November 2026). Its README records their source as the Google favicon service for the respective service websites. The preview does not retain exact download URLs or license grants; no open-source license is asserted for these brand marks. Marks remain the property of their respective owners and identify the named services only.

The application serves these files locally. It does not fetch third-party icons at runtime. Emkan, SNB, Mada, STC Pay and other brands without an appropriate bundled mark use a plain text name badge, not a claimed official logo. Unknown identities use the existing generic resource icon.
