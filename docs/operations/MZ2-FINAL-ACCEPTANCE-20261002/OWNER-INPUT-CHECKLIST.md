# قائمة إدخالات OWNER — حسب ترتيب التعبئة المعتمد

**وقت الرصيد المعتمد لكل بند:** 2026-10-03 00:00:00، Asia/Riyadh +03:00
(`2026-10-02T21:00:00Z`). مصدر الجرد والأرصدة والديون هو **OWNER MANUAL INPUT**.
صاحب الاعتماد النهائي **OWNER**. هذا تحضير وقبول مدخلات فقط؛ لا تنفيذ على Production.

لم تُقدم أرقام أو كميات أو تكاليف أو هويات حسابات فعلية بعد. جميع الخانات غير
المعبأة في [حزمة الاعتماد](FINAL-BUSINESS-UAT-APPROVAL-PACK.md) تبقى
**PENDING_OWNER_INPUT**، بما فيها صفر وعدم الانطباق حتى تقرهما صراحة.
لا إعادة إدخال لتاريخ القطع أو طريقة المصدر؛ تم اعتمادهما بالفعل.

## حقول مشتركة لكل إدخال

- اسم الصنف/الحساب/الطرف والهوية الموجودة في النظام، ونطاق المالك/المنشأة.
- القيمة التي تدخلها صراحة، وحدتها أو عملتها، وطبيعتها: مستحق لنا/علينا/صفر صريح.
- وقت القيمة أو العد، وجسر موثق للقطع إن اختلف الوقت؛ لا تعديل التاريخ تلقائيًا.
- مرجع سجل الإدخال اليدوي ونسخته، هوية من أدخله ووقت الإدخال، والمرفق المطلوب
  في العقد إن وجد. البصمة تحفظ عند وجود أصل فعلي؛ لا نختلقها مسبقًا.
- الرصيد/المصدر المقارن إن توفر، والفرق وتفسيره وقرارك بشأنه. غياب المقارن لا يعني تطابقًا.
- اعتمادك النهائي للقيمة/النسخة بعد المراجعة؛ لا اعتماد شامل لأرقام لم تُدخل.

مصدر الإدخال وصاحب الاعتماد معروفان: OWNER MANUAL INPUT / OWNER؛ الاسم
وowner_id الفعليان غير المقدمين يظلان PENDING_OWNER_INPUT. لا بيانات حساسة في GitHub.

## 1. الجرد

- قائمة كل منتج وخيار ومكوّن وهويته canonical، مع صف مستقل لكل خيار.
- الكمية المعدودة، الوحدة، تكلفة الوحدة المعتمدة وعملتها ودليلها، والقيمة الإجمالية
  عند توفر مدخلاتها؛ لا تكلفة أو كمية افتراضية.
- كل مستودع/موقع وهوية الموقع وباركوده والكمية المخصصة له وحالة التجهيز/المواصفات.
- حساب المخزون الموجود لكل صنف، ووقت العد، ومرجع ورقة الجرد/الإدخال اليدوي.
- كمية المصدر المقارن إن وجدت، الفرق وتفسيره/إعادة العد، والكمية التي تعتمدها.
- هوية مسؤول العد ومراجع المحاسبة إن كانا غيرك؛ اعتماد الأرقام النهائي لك بصفتك OWNER.

تراجع لاحقًا: مجموع المواقع = كمية الهوية؛ الكمية × التكلفة = قيمة السطر؛ مجموع
الحساب يطابق تقييمه المعتمد. الفروق ظاهرة ولا تسوية أو تعديل تاريخي تلقائي.
توقيع حقائق الجرد لا ينفذ Inventory initialization.

## 2. البنوك والصناديق

- كل حساب بنكي: الاسم/الهوية، العملة، الرصيد الذي تدخله عند القطع، ومرجع المصدر.
- كل صندوق: الاسم/الهوية، العملة، مبلغ النقد الفعلي ووقت عده.
- السحب على المكشوف إن وجد: هويته ورصيده مستقلًا، دون دمجه مع الصندوق.
- الفروق والبنود المعلقة وتفسيرها، وأي سعر صرف ودليله إذا تطلب العقد تحويل العملة.
- أدخل صفر الحساب أو عدم انطباقه صراحة عند تحقق ذلك، ولا تترك الفراغ بمعنى صفر.

## 3. مزودو الدفع

- أسماء المزودين المنطبقين وهوياتهم القائمة، مع قرارك الصريح بشأن غير المنطبق.
- الرصيد لكل مزود عند القطع، واتجاهه، والعملة والبنك المرتبط بهويته canonical.
- مبالغ ومراجع العمليات والتسويات المعلقة، الرسوم/الضرائب، والاستردادات المعلقة، كل منها منفصل.
- مرجع إدخالك/كشف المراجعة ووقته، والفرق بينه وبين الرصيد المقترح وتفسيره.
- إن ظهر مبلغ لا يقبله التصنيف الحالي، يسجل للمراجعة ولا يُحوّل إلى هوية بديلة بالتخمين.

## 4. شركات الشحن/COD

- كل شركة بهويتها والعقد/السياسة القائمة المنطبقة.
- إجمالي COD غير المحصل لنا عند القطع، مع قائمة الشحنات/التحصيلات المرتبطة.
- الأجرة والرسوم وVAT غير المدفوعة للشركة، منفصلة عن COD.
- مراجع التوريدات/التحصيلات والفواتير والتسويات المعلقة والفروق.
- اعتمادك لكل ذمة واتجاهها دون مقاصة تلقائية.

## 5. المندوبون

- كل مندوب باسمه وهويته الموجودة؛ لا رصيد مجمع أو مندوب افتراضي.
- COD الذي تدخله كذمة عليه عند القطع، والأجرة المستحقة له منفصلة.
- النقد الفعلي في العهدة إن توفر، ومراجع التسليم/C3 والتوريد الحالية، والفرق إن وجد.
- مدفوعات التحويل البنكي/POS المعلقة ومراجع الأدلة وحالة المراجعة القائمة.
- عند وجود ذمة POS: هويتها الموثقة القائمة وقيمتها وحالة التسوية البنكية؛ لا
  تعامل كـBank ولا تُخصم من ذمة المندوب بمجرد إدخالها. تُمنع إعادة احتساب المبلغ بين الصفوف.
- قرارك بالمطابقة النهائية للأرقام، دون تعديل C3 المختوم أو إعادة كتابة دليل تاريخي.

## 6. الموردون

- كل مورد بهوية C1/C2 الموجودة ومرجع سجل الإدخال.
- الفواتير المفتوحة: رقم/تاريخ/عملة/أصل المبلغ/المدفوع حتى القطع/المتبقي.
- الرصيد المستحق للمورد، والدفعات المقدمة له في صفوف منفصلة.
- مراجع السداد والمطابقة والفروق والمبالغ محل المراجعة، ثم اعتمادك للأرصدة.

## 7. العملاء/الحقوق

- كل عميل/طرف بهويته الموجودة، وأصل الحق أو الدين ومرجع الطلب/المستند.
- المبلغ الذي تدخله، اتجاهه لنا/علينا، عملته وتوقيته والمسدّد والمتبقي.
- مراجع الحقوق أو الاستردادات أو الدفعات المقدمة المفتوحة إن وجدت.
- التصنيف الافتتاحي القائم الموافق للحركة؛ إذا لم يثبت، تبقى فجوة ولا نختار
  customer_receivable أو other_payable بدلًا منه بالتخمين.
- قرارك في كل فرق أو نزاع، ولا استنتاج دين من بيانات قديمة غير معتمدة.

## 8. الالتزامات والضرائب

- كل التزام/جهة: الهوية، أصل الاستحقاق وفترته، العملة، المبلغ المستحق وغير المدفوع حتى القطع.
- المصروفات المستحقة والذمم الدائنة الأخرى منفصلة حسب التصنيف القائم.
- ضريبة المبيعات المستحقة وضريبة المدخلات كل منهما مستقل، مع الفترة والمرجع الذي تعتمد عليه.
- المدفوع أو المسوّى حتى القطع والمعلّق والفروق، دون مقاصة أو تسوية تلقائية.
- إقرارك الصريح بكل قيمة أو صفر/عدم انطباق، وفق العقد الموجود.

## 9. أي أرصدة افتتاحية أخرى مطلوبة

- **الموظفون:** كل هوية موظف ورصيد الراتب المكتسب غير المدفوع والسلفة والعهدة،
  ثلاثة أرصدة منفصلة، مع الفترة والمدفوعات/المراجع القائمة.
- **الإعلانات:** هوية الحساب وربط Track E، المحفظة المدفوعة مقدمًا والمستحقات
  منفصلان، العملة والمراجع والتمويل/السداد المعلق؛ لا إذن إنفاق إعلاني جديد.
- **المصروفات المدفوعة مقدمًا:** الفاتورة/الالتزام القائم، المدفوع، بداية/نهاية
  التغطية والجزء المتبقي عند القطع؛ لا فترة أو مبلغ محسوب من مدخل ناقص.
- **حقوق الملكية:** مستندات رأس المال والمساهمات/السحوبات، وأي تفسير لفرق
  المعاينة الذي يظهر وفق العقد؛ لا مبلغ موازن أو حساب افتراضي مخترع.
- **ذمم مدينة/دائنة أخرى:** الجهة والهوية والتصنيف القائم واتجاه ومبلغ الرصيد
  الذي تدخلُه، مع أصله ومرجعه. أي رصيد خارج العقد يظل فجوة للمراجعة.
- **تقييم المخزون الافتتاحي:** إجمالي كل حساب محسوب من جردك المعتمد عند اكتماله؛
  ليس رصيدًا إضافيًا يُدخل مرة ثانية في مكان آخر.

## بعد اكتمال التعبئة — مراجعة مؤجلة دون تنفيذ

OWNER يعتمد snapshot/version/fingerprints والفروق والنتيجة التجارية للنسخة
الفعلية بعد مراجعتها. جميع قيم هذه النسخة وتوقيعها الآن PENDING_OWNER_INPUT.
OWNER هو صاحب التفويض النهائي لبوابات Opening/Inventory/Activation/P08 ونافذة
الاستقرار؛ لم يصدر أي منها. تعيين صاحب التفويض لا يفتح409 ولا يغير423 أو التحكم.

**Production financial writes=0؛ Opening/Activation/Inventory initialization/
Backfill/Release lease/Merge/Deploy=NO؛ write-control UNCHANGED.**
لا Production mutation أو live reconciliation. توقف بعد تجهيز هذه القائمة.
