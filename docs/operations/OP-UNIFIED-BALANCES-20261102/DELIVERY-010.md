# القيد 010 — تأكيد هوية مشروع ميزان والوصول إلى بوابة محرر المضيف

3 نوفمبر 2026. سجل المهمة الدائم: [#1687](https://github.com/AMASI-SA/AMASI-SA/pull/1687). المرشح المجمّد: [#1702](https://github.com/AMASI-SA/AMASI-SA/pull/1702). هذا قيد توثيق بعد [القيد 009](DELIVERY-009.md)، وليس تغييرًا في كود الإصدار.

## ما تغير منذ القيد 009

أكد المالك مباشرةً أن التطبيق المسمّى **Salla Analytics** في إدارة Emergent هو مشروع ميزان المقصود. فُتح من جلسة الإدارة المسجّلة، ثم من قائمة Code عبر Open in VS Code ثم Open in Browser. وصل هذا المسار إلى صفحة تسجيل الدخول الخاصة بمحرر code-server على المضيف الأصلي. بذلك حُسمت هوية المشروع، وأصبح العائق الحالي دخول المحرر نفسه. لا تحل جلسة إدارة Emergent تلقائيًا محل جلسة المحرر.

## ما لم يُنفَّذ

لم تُفتح طرفية موثقة داخل المضيف ولم يُنفّذ أمر حالة حارس الإصدار. حالة الحجز الفعلي **غير معلومة**؛ لا يوجد دليل جديد على أنه نشط أو غير نشط. ولم يُثبت بعد قبول العرض على الكمبيوتر والجوال، أو الطباعة الفعلية وفتح ملف Excel المنزّل. خطوات قبول المعاينة الاصطناعية محفوظة في القيد 009. لم يُشغّل هنا اختبار جديد ولا تُحتسب اختبارات 008 مرة أخرى.

عند التوثيق، أعاد GitHub المرشح #1702 بحالة مسودة مفتوحة وغير مدمجة، ورأسه B2 `4b7eed3b40aae718a6652486010342c9d3701261`. نطاق الإصدار باقٍ: الربطان R03 وR05 مع جميع الإصلاحات الجاهزة. إثباتات A2/B2 ونتائج الفحوص في [القيد 008](DELIVERY-008.md). لم تُعدّل هذه المرحلة المرشح أو الإنتاج أو أرصدة المتجر.

## الخطوة التالية

أكمل دخول المحرر عبر واجهته الرسمية، ثم اقرأ فقط:

```bash
cd /app && python3 -B scripts/production_release_guard.py status
```

سجّل الناتج الفعلي قبل أي إجراء نشر، وأكمل القبول البصري في بيئة معاينة مأذونة. إذا كان الحجز لعمل آخر فلا تغيّره. بعد تحقق البوابتين، أعد فحص رأس الإنتاج قبل دمج المرشح وفق بروتوكول v5. اعتماد أي فروق فواتير أو رواتب فعلية منفصل عن نشر الكود.

**دمج المرشح: لا. نشر: لا. تعديل حجز: لا. تفعيل أو كتابة مالية فعلية: لا.**
