1. **حالة المضيف الحقيقي غير معروفة.** صفحة الطرفية المعروفة في Emergent أعادت “Preview Unavailable” وذكرت أن مساحة التطوير نائمة بعد عدم النشاط. صفحة الإدارة عرضت تسجيل الدخول. لم يُنفّذ أي أمر في `/app`. هذه حالة مساحة التطوير، وليست دليلًا على توقف الموقع المنشور.
2. [آخر دليل للمهمة الأخرى #1701](https://github.com/AMASI-SA/AMASI-SA/pull/1701#issuecomment-6590719796) يثبت نجاح `prepublish` لذلك الإصدار حينها، وليس إغلاق حجزه الآن. بعد الدخول إلى الإدارة وإيقاظ مساحة التطوير: نفّذ للقراءة فقط `cd /app && python3 -B scripts/production_release_guard.py status`. إن كان الحجز نشطًا لمهمة أخرى فلا يُمس؛ لا تستنتج الحجز من GitHub أو من حالة المعاينة.
3. **الفحص البصري الفعلي ما زال مفتوحًا.** مخرجات B2 المعاينة من GitHub هي نتائج اختبارات/بناء، وليست لقطة لشاشة التقرير أو ملف PDF مطبوعًا أو XLSX منزّلًا من المتصفح. بيئة المعاينة السابقة رفضت الوصول قبل الرسم. لا يُعاد توصيف اختبار الوحدات كقبول متصفح.
