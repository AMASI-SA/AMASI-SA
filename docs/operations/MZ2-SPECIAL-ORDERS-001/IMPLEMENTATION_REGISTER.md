## ما يعمل برمجيًا وما لم يكتمل

الموجود: طلبات خاصة وهوية وأصل/خيارات مستقلة، مساهمة وتحويل/إيصال مثبت، native supplier/inventory، تحصيل/أجرة/عهدة/تسويات جزئية وصافية وإعادة إسناد الموصل، ملفات المورد والبوليصة الخاصة والروابط المصادق عليها، ضابط معاملات محلية مع تدقيق ورفض missing-state وstale-epoch وحذف التاريخ والbulk.

المتبقي: مصالحة استلام المورد مع أحدث الإنتاج؛ تسوية رصيد سلة المخزنة ومربوطة بالتحصيل؛ مستهلكو التقارير/KPI الفعلية؛ التغطية الكاملة لجميع الأغراض والعملات وشركات الشحن؛ جرد العاملين والكتّاب القدامى والجداول المشتركة/الآثار الخارجية؛ اختبار الحمل؛ نسخ الويب وتطبيقي Android؛ هدف رجوع واستعادة backup وتجربة rollback معزولة ومراجعة مستقلة.
وجود الضابط في الكود لا يعني أنه فُعّل أو أثبت إيقاف كل عامل في البيئة. لا تعالج البنود الناقصة بفتح static gates أو إنشاء قيود حية.
