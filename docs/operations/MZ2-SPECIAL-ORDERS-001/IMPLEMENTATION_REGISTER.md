## تفاصيل R5 دون مبالغة في القبول

تقرير المحادثة السابقة أفاد باختبارات محلية للطلب المجاني والجزئي والتسويات وملف PDF وQR؛ **ملفات الأدلة الأصلية لتلك التشغيلات غير مضمنة في هذه الحزمة**، لذلك لا تُرفع إلى مستوى قبول مستقل هنا.
المثبت في جولة الاستعادة: تطابق كل33 بصمة سابقة ولاحقة، نجاح git apply --check على fixture معزول، تطبيقها على نسخة اختبار فقط وفحص26 ملف Python نحويًا. اختبارات React/المتصفح والجهاز والتشغيل الكامل يجب إعادتها على المصدر المثبت الذي سيُراجع.

## المتبقي، بترتيب الاستئناف

1. تحويل R5 المحفوظ إلى مصدر عادي فوق أحدث رأس بعد المقارنة، ثم تثبيته واختباره بالكامل. لا تعِد تطبيق R3/R4 أو R5 عند وجود البصمات الجديدة بالفعل.
2. استكمال **تسوية رصيد سلة المخزنة** وإسنادها للبنك/COD والبوليصة والتسوية دون تغيير بيع سلة أو تكرار رصيده.
3. استكمال **التقارير الفعلية**: تكلفة التعويض/الهدية/المحتوى والربحية والأرصدة، استبعاد العدد والإيراد التسويقي المناسب، وعدم مضاعفة الشحن أو أجرة الموصل.
4. تنفيذ وربط **ضوابط الإيقاف الموثوقة عبر كل الكتّاب** وتجربة رقم جيل الكتابة والعمليات المختلطة والعودة للقراءة فقط. البوابات المكتوبة الحالية لا تكفي لإثبات ذلك.
5. مطابقة فروع الإنتاج والمحاسبة الأحدث دون فقد الإصلاحات أو خلط اعتماد فروع أخرى. يشمل ضوابط Fail-Closed والمحاسبة وRelease Guard التي لم تُستورد آليًا.
6. فحص نماذج الهاتف والويب الفعلية، وحماية إيصالات البنوك، والطباعة والبوليصات الخاصة، وأرقام MZ الطويلة، والعملات، وخيارات ملفات المنتج غير المدعومة قبل تفعيلها.
7. فحوص دورة كاملة عادية/خاصة، أكثر من موظف/موصل، الإلغاء والاسترداد وإعادة المحاولة وتغيّر حالة المصدر، ثم Preview UAT ونسخة رجوع متوافقة وتجربة استعادة معزولة.
8. توثيق خطة الإصدار/الرجوع الموقعة؛ التفويض المستقل مطلوب لكل نشر أو تفعيل أو رجوع حي. يبقى PR Draft حتى ذلك.
