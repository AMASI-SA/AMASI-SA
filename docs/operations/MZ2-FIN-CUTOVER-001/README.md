## قاعدة قفل المراحل

كل مرحلة لها بوابة خروج واضحة. لا تنتقل الحالة إلى `COMPLETE` إلا عند تحقق جميع ما يلي:

- اكتمال الكود والواجهة ضمن نطاق المرحلة.
- نجاح اختبارات Backend وFrontend ذات الصلة.
- نجاح بناء Production Frontend.
- دمج PR في `hotfix/prod-snap-meta-final`.
- النشر الفعلي عند وجود تغيير Runtime، وفق `production_release_guard.py`.
- التحقق من Production بعد النشر.
- تنفيذ اختبار متصفح بالسيناريوهات المحددة في ملف المرحلة.
- تسجيل الأدلة والـPR والـMerge SHA ونتيجة التحقق في `STATUS.json` وملف المرحلة.
- عدم وجود بند قبول مفتوح أو بيانات مجهولة تم تمريرها بصمت.

إذا أخفق أي بند، تبقى المرحلة `IN_PROGRESS` أو `BLOCKED`، وتبقى جميع المراحل التالية `BLOCKED_BY_PREVIOUS_PHASE`.

## سياسة ميزان القديم — النسخ فقط، لا اعتماد مالي

يسمح باستخدام ميزان القديم **مرة واحدة للنسخ المرجعي فقط** في الحالات التالية:

- أسماء شركات الشحن.
- تكلفة افتراضية للشحنة.
- نسب ورسوم COD الافتراضية.
- أسماء مناديب التوصيل.
- سعر التوصيلة الحالي.
- أسماء الموردين أو الموظفين أو الحسابات بوصفها بيانات تعريفية.

أي قيمة منسوخة يجب أن تدخل ميزان 2 بهذه الصفة:

- `source_kind = legacy_copy`
- `verification_status = unverified`
- `approved_by = null`
- `approved_at = null`
- لا تنشئ قيدًا ولا رصيدًا ولا تقريرًا ماليًا معتمدًا قبل تأكيد المالك أو إرفاق الدليل.

بعد مراجعة المالك تصبح القيمة إعدادًا مستقلًا داخل ميزان 2، ولا يجوز للنظام قراءتها ديناميكيًا من ميزان القديم مرة أخرى.

ممنوع نسخ أو اعتماد ما يلي من ميزان القديم:

- الأرصدة البنكية أو أرصدة المزودين وشركات الشحن.
- مبيعات أو أرباح أو ضرائب أو قيود تاريخية.
- ذمم الموردين أو الموظفين أو الموصلين.
- قيمة المخزون الافتتاحية.
- أي مركز مالي أو رصيد افتتاحي.

هذه البنود لا تقبل إلا من أدلة القطع المعتمدة في P07.

## سياسة إدخال البيانات عبر المتصفح

المحادثة التي تستخدم المتصفح السحابي تعمل وفق الآتي:

- تدخل الإعدادات أو المسودات المسموح بها دون ترحيل مالي غير مصرح.
- لا تضغط «ترحيل»، «اعتماد»، «تفعيل القطع» أو أي إجراء غير قابل للعكس إلا بتفويض صريح في نفس المحادثة وبعد تحقق بوابة المرحلة.
- لا تحفظ كلمات المرور أو OTP أو التوكنات أو أرقام الحسابات الكاملة في GitHub.
- تسجل مرجع المستند أو آخر أربع خانات فقط عند الحاجة؛ المستندات الحساسة تبقى في مخزن التطبيق أو الملفات المصرح بها.
- توثق ما أُدخل وما بقي وما فشل، ثم تحدث ملف المرحلة و`STATUS.json` عبر PR.
