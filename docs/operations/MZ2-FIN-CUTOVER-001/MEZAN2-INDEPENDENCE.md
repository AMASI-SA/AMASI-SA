# استقلال ميزان 2 — شرط قبول الإنتاج

توجيه المالك بتاريخ 2026-09-17: ميزان 2 يجب أن يعمل بالكامل بعد إيقاف ميزان القديم نهائيًا.

- لا تعتمد وظائف ميزان 2 على صفحات القديم أو واجهاته أو مجدولاته أو حساباته التحليلية.
- الاستيراد والتحديث والمطابقة والصلاحيات والتقارير لها مسارات يملكها ميزان 2. البيانات المرجعية المنسوخة مرة واحدة لا تصبح اعتمادًا تشغيليًا متجددًا.
- استيراد Excel يجب أن يحفظ أرقام الطلبات والعناصر والكميات والعملات والتاريخ الأصلي وتفاصيل المبالغ، مع مقارنة مستقلة بالمصدر. نجاح عدد الصفوف وحده لا يكفي.
- شرط القبول: تعطيل مسارات ومجدولات القديم في Preview ثم اختبار بدء التشغيل، الدخول والصلاحيات، الاستيراد، قائمة/بحث/تفاصيل الطلبات، والتسويات والتقارير المتاحة ضمن بوابة المرحلة. مراقبة عدم وجود أي استدعاء لمسار قديم.
- القيود والأرصدة القديمة لا تُرحّل تلقائيًا. تستمر سياسة يوم القطع والأرصدة الافتتاحية اليدوية وبوابات المراحل.

## الحالة

عرض Excel المباشر عبر Order Engine يعمل في Preview دون استدعاء واجهة تحليل القديم. مطابقة التسوية المجمعة نجحت. لكن تحميل البيانات تم بالاستيراد القديم سابقًا؛ لم يتحقق استقلال مسار الإدخال. كما كشف الفحص فقد عناصر الطلبات والتوقيت التفصيلي وخطأ تعيين أحد مبالغ السلة. لا يعد النظام جاهزًا للإنتاج حتى إصلاح هذه النقاط وإتمام اختبار إيقاف القديم.

## التنفيذ التالي

ابدأ باستيراد مستقل داخل ميزان 2 مع اختبارات دقة المصدر، ثم أعد التحقق من القائمة والتفاصيل والمطابقة. لا تكرر الاستيراد القديم كحل دائم ولا تعلن الجاهزية اعتمادًا على ظهور الطلبات فقط.

لتفادي ملفات bytecode غير المشتقة أثناء فحص المصدر المحكوم، شغّل أوامر Python للاختبار والصيانة بـPYTHONDONTWRITEBYTECODE=1 وpython -B داخل نسخة اختبار مستقلة.
