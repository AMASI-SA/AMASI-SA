## نتيجة الجرد

لدينا تعريفات شركات، حاسبة شرائح، ربط بنك P01، هويات مناديب ولقطات أجرة، وجسور قديمة. لكن لا يوجد في المسار المفحوص تكامل P02 مقبول يجمع هوية الشحنة، استحقاق التكلفة، عهدة COD، دليل الكشف، والتحويل عبر حدود P01 الحالية. أبرز الموانع:

- جسر المندوب يقابل COD بإيراد؛ لا يصلح للتوصيل بجوار اعتراف النواة دون منع ازدواج الإيراد والضريبة.
- تسوية الشركة القديمة تعيد خصم تكلفة الشحن كمصروف؛ لا تصلح لتسوية تكلفة مثبتة سابقًا.
- دفاتر عرض قديمة تعيد الحساب من الطلب والإعداد الحالي؛ ليست مصدر ذمم ثابتة لكل شحنة.
- P01 يقيد تسويات/إيصالات المزودين بأربعة مزودي دفع، ولا يقبل الشحن أو إيصالًا بقيمة صفر. نحتاج عقد توسعة موثق للمقاصة، لا إيصال بنك صوري.
- `store_drivers.id` موجود، ومسار آخر يستخدم `users.id`؛ الربط التشغيلي المعتمد يجب حسمه بالدليل قبل الترحيل.
